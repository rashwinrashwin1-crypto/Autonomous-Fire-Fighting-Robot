# Autonomous Fire Fighting Robot

An Arduino-based autonomous robot designed to detect and extinguish fire automatically.

## Project Description

The robot uses a flame sensor to detect fire and an Arduino UNO to control the robot movement and fire extinguishing mechanism.

## Components Used

- Arduino UNO
- Flame Sensor
- Temperature Sensor
- L298N Motor Driver
- BO Motors
- Water Pump
- Relay Module
- Rechargeable Battery
- Robot Chassis

## Working

1. The flame sensor detects the presence of fire.
2. The sensor sends the signal to the Arduino UNO.
3. Arduino processes the sensor input.
4. The L298N motor driver controls the motors.
5. The robot moves towards the fire source.
6. The water pump is activated to extinguish the fire.

## Technologies Used

- Arduino UNO
- Embedded C/C++
- Arduino IDE
- Sensor Interfacing
- Motor Control

## Project Result

The robot is designed to detect a fire source and automatically activate the fire extinguishing mechanism.
